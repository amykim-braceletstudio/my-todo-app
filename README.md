# 📝 나의 첫 To-Do 앱 (My First To-Do App)

깃허브(GitHub) 기초부터 브랜치 관리, Pull Request, GitHub Pages 배포까지 직접 실습하며 만든 **할 일 관리 웹 앱**입니다.

---

### 🌐 실제 배포 주소
👉 **[웹 앱 직접 써보기 (클릭!)](https://amykim-pnc.github.io/my-todo-app/)**

---

### ✨ 주요 기능
- ➕ **할 일 추가:** 입력창에 오늘 할 일을 입력하고 추가 버튼을 눌러 목록에 등록
- ✔️ **완료 표시:** 등록된 할 일 항목을 클릭하면 취소선과 함께 완료 처리
- 🗑️ **할 일 삭제:** 삭제 버튼을 눌러 목록에서 항목 제거

---

### 🛠️ 사용한 기술 스택 (Tech Stack)
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Version Control & Hosting:** Git, GitHub, GitHub Pages

---

### 🚀 학습한 Git 핵심 라이프사이클
1. `git clone` - 원격 저장소를 로컬 컴퓨터로 복제
2. `git checkout -b [브랜치명]` - 기능별 독립 작업 영역 생성
3. `git add .` & `git commit` - 변경 사항 스냅샷 기록
4. `git push` - GitHub 원격 저장소에 업로드
5. **Pull Request & Merge** - 코드 리뷰 및 메인 브랜치 병합
6. **GitHub Pages** - 웹 사이트 자동 배포
